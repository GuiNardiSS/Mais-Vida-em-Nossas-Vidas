# Vídeo de Assinatura

## Instruções

Coloque o vídeo de apresentação das assinaturas neste diretório com o nome:

**`video_assinatura.mp4`**

### Formato recomendado:
- Formato: MP4 (H.264)
- Resolução: 1920x1080 ou 1280x720
- Duração: 30 segundos a 2 minutos
- Proporção: 16:9 (horizontal)

### Como adicionar o vídeo:
1. Copie o arquivo de vídeo para este diretório
2. Renomeie para `video_assinatura.mp4`
3. O app carregará automaticamente

### Caso o vídeo não esteja disponível:
O app mostrará uma mensagem "Vídeo não disponível" com um ícone.

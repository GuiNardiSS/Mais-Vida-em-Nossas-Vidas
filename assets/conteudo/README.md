## 🎬 Gerar Vídeos com Narração

Execute o script Python para gerar automaticamente os 10 vídeos:

```bash
pip install moviepy gtts pillow
python gerar_videos.py
```

**Vídeos que serão gerados:**

- autoconhecimento.mp4
- gratidao.mp4

- resiliencia.mp4
- compaixao.mp4
- proposito.mp4

- amor.mp4

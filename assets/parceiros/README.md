# Imagens de Parceiros

Esta pasta contém as imagens/logos dos parceiros exibidos na página "Espiritualidade no dia a dia".

## Imagens Necessárias

### Bele Beauty Store
- **Nome do arquivo**: `bele_beauty_store.png`
- **Descrição**: Logo circular com fundo preto, texto "BELE" em branco e "beauty" em dourado
- **Status**: ✅ Adicionado
- **Formato**: PNG
- **Recomendação**: Resolução mínima 400x400px para melhor qualidade

### Reffinatto Brazil
- **Nome do arquivo**: `reffinatto_brazil.png`
- **Origem**: Arquivo "REFINATTO BRAZIL ILUSTRATOR.ai" fornecido
- **Ação Necessária**: Converter o arquivo .ai para .png e salvar nesta pasta
- **Status**: ✅ Adicionado
- **Formato**: PNG

## Instruções

1. Salve as imagens com os nomes exatos listados acima
2. Formato recomendado: PNG com transparência (quando aplicável)
3. Dimensões sugeridas: 400x400px ou maior
4. Após adicionar as imagens, o app as carregará automaticamente

## Nota
Se uma imagem não existir, será exibido um ícone placeholder no card do parceiro.

# Vídeo de Boas-Vindas

## 📹 Como Adicionar o Vídeo

Coloque o vídeo de boas-vindas neste diretório com o nome:

**`video_boas_vindas.mp4`**

### ✅ Formato Recomendado:
- **Formato:** MP4 (H.264)
- **Resolução:** 1920x1080 (Full HD) ou 1280x720 (HD)
- **Proporção:** 16:9 (horizontal)
- **Duração:** 15 a 60 segundos
- **Tamanho:** Máximo 10 MB para melhor performance

### 📝 Passos para Adicionar:
1. Copie seu arquivo de vídeo para este diretório:
   ```
   assets/intro/
   ```

2. Renomeie o arquivo para:
   ```
   video_boas_vindas.mp4
   ```

3. O app carregará o vídeo automaticamente na próxima execução

### 🎬 Comportamento do Player:
- ▶️ O vídeo inicia automaticamente ao abrir o app
- 🔄 Reproduz em loop contínuo
- 🎵 Controle de som (mute/unmute) no canto superior direito
- ⏯️ Toque na tela para pausar/retomar
- 📱 Responsivo e adaptado ao tamanho da tela

### ⚠️ Caso o Vídeo Não Esteja Disponível:
O app mostrará:
- 🎥 Ícone de câmera desligada
- 📄 Mensagem "Vídeo não disponível"
- ✅ A funcionalidade do app continua normalmente

### 🔧 Dicas de Otimização:
- Comprima o vídeo antes de adicionar (use HandBrake ou similar)
- Use bitrate entre 2-5 Mbps para boa qualidade
- Prefira resolução 720p para melhor performance em dispositivos móveis
